Portfólio Pessoal

1. Sobre o projeto
Portfólio pessoal desenvolvido no Figma Make como atividade acadêmica, apresentando minha trajetória, stack técnica e projetos como estudante de Engenharia de Software.

 2. Estrutura
O portfólio é dividido em 4 seções principais: apresentação, habilidades técnicas, projetos desenvolvidos e página individual de detalhe de cada projeto, seguindo os requisitos da atividade.

 3. Telas desenvolvidas
Telas do portfólio, na ordem de navegação do usuário:

1. `01-tela-inicial-home.png` — Página inicial, com apresentação, nome, trajetória e áreas de interesse
2. `02-Habilidades.png` — Stack técnica organizada por categoria (linguagens, frontend, backend, banco de dados, ferramentas)
3. `03-Projetos.png` — Grid com os projetos desenvolvidos (TaskFlow e DevLinks)
4. `03-Projetos2.png` — Continuação do grid de projetos (Finance API e GameTracker)
5. `04-Tela TaskFlow.png` — Página de detalhe do projeto TaskFlow
6. `05- Tela DevLinks.png` — Página de detalhe do projeto DevLinks
7. `06-Tela GameTracker.png` — Página de detalhe do projeto GameTracker
8. `07- Tela Finance Api.png` — Página de detalhe do projeto Finance API
